# 🕰️ Classic Analog Clock

A clean, responsive, and elegant analog clock web application built with HTML5, Tailwind CSS, and vanilla JavaScript. Designed with a warm, vintage parchment aesthetic, this component accurately displays real-time hours, minutes, and seconds using smooth CSS rotational transforms.

---

## ✨ Features

* **Classic Vintage Aesthetic:** Soft warm face (`amber-50`), rich stone framing, and distinct dark hands.
* **Accurate Hand Rotations:** JavaScript logic dynamically calculates rotational degrees for smooth, accurate movement (including proportional hour-hand progression).
* **Responsive & Centered Design:** Fully centered layout using Flexbox and Tailwind CSS utilities.
* **Zero Dependencies:** Uses standard JavaScript and CDN-hosted Tailwind CSS—no build tools or complex frameworks required.
